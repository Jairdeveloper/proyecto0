Diseña una página web moderna, profesional y totalmente responsive para un servicio de acortamiento de enlaces. La página debe tener una interfaz limpia con un formulario principal donde el usuario pueda introducir una URL larga y obtener un enlace corto. Incluye una sección de estadísticas que muestre clics, fecha de creación, país y dispositivo de acceso. Agrega autenticación de usuarios, panel de control, historial de enlaces, códigos QR para cada enlace y opciones de enlaces personalizados. Utiliza una paleta de colores moderna, tipografía clara y animaciones sutiles. Prioriza velocidad, accesibilidad, experiencia de usuario y diseño SaaS profesional.
